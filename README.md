# BLinkeRs — Hyperlocal Delivery App

A full-stack hyperlocal delivery platform built for Tier-2/3 Indian cities.

## Apps included

| Route | Description |
|-------|-------------|
| `/` | Customer app — browse, checkout, track orders |
| `/vendor` | Vendor app — orders, inventory, daily sales |

## Tech Stack
- React 18 + Vite
- React Router v6
- Supabase (backend — coming soon)

## Run locally
```bash
npm install
npm run dev -- --host
